📡 Configuração do Bot do Telegram

Aqui você configura a integração com o Telegram. O sistema envia mensagens automáticas (abertura de TTKs, solicitações de atualização e resumo diário) para os grupos de cada região.

Como funciona: Crie um bot no Telegram via @BotFather, copie o token gerado e cole no campo abaixo. Depois, adicione o bot como membro em cada grupo regional e insira o Chat ID do grupo correspondente.

💡 Para descobrir o Chat ID, adicione o bot ao grupo, envie uma mensagem e acesse:
https://api.telegram.org/bot<SEU_TOKEN>/getUpdates
